# Bar Order App 🍹

A modern bar ordering system with QR code table ordering and in-app payments.

## Quick Deploy to Vercel

1. Push this code to GitHub
2. Go to [vercel.com](https://vercel.com)
3. Click "New Project"
4. Import your GitHub repository
5. Deploy! (Vercel auto-detects Vite config)

## Local Development

```bash
npm install
npm run dev
```

Visit: `http://localhost:5173?table=1`

## Features

- 📱 QR code table ordering
- 🛒 Shopping cart
- 💳 Payment integration (Stripe ready)
- 👨‍💼 Staff dashboard
- ⚡ Real-time order updates

## Usage

**Customer URL**: `yourapp.vercel.app?table=5`
**Staff Dashboard**: Click "Staff" button in bottom-right

Generate QR codes for each table at: [qr-code-generator.com](https://www.qr-code-generator.com)

## Tech Stack

- React 18
- Vite
- Tailwind CSS
- Lucide Icons
